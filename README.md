# Riding Analysis Dashboard 🚲🚗

> A comprehensive data analysis and visualization project analyzing ride-booking trends using Power BI.

---

## 📂 Repository Structure

* **`yt.pbix`**: The main Power BI dashboard file containing data models, DAX measures, and interactive visualizations.
* **`rideBookings.csv`**: The underlying dataset containing raw ride-booking records.

---

## 📊 Project Overview

This repository focuses on analyzing ride-booking patterns to extract meaningful business insights. By leveraging Power BI, the project visualizes key performance indicators (KPIs) such as:
* Total bookings and ride volume trends over time.
* Revenue and pricing patterns.
* User/rider demographics and behavior metrics.
* Peak booking hours and geographical/route distribution.

---

## 🛠️ Tools & Technologies Used

* **Power BI Desktop**: For data transformation, modeling, DAX calculations, and report building.
* **CSV / Excel**: For raw data storage and preprocessing.
